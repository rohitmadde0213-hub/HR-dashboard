# HR-dashboard
Excited to share my latest Human Resources Dashboard, where I combined data skills and design thinking using multiple tools: 🛢️ BigQuery SQL | 📊 Excel | 🗂️ Draw.io | 🎨 Figma | 📈 Tableau
💡 Here’s how I approached it:
🔸 Data Preparation (SQL & Excel)
 – Cleaned and transformed raw HR data using SQL
 – Performed exploratory analysis and validation in Excel for salary, department, and demographics

🧠 Planning & Structure (Draw.io)
 – Mapped out dashboard components, navigation flow, and user interactions
 – Created a wireframe blueprint before building visuals

🎨 UI/UX Design (Figma)
 – Prototyped a clean layout with modern styling and clear visual hierarchy
 – Focused on user-friendly design principles

📊 Visualization & Interactivity (Tableau)
 – Built a fully interactive dashboard with filters, KPIs, and drill-downs
→ Covered employee distribution, salaries, hiring trends, performance, and more

✅ Tools Used:
🛢️ BigQuery SQL
 📊 Excel
 🗂️ Draw.io
 🎨 Figma
 📈 Tableau
